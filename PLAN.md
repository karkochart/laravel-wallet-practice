# План на 2 дня: Laravel + PostgreSQL + крипто-ядро (подготовка к собеседованию на PHP/Laravel в финтех и крипто)

Цель не «написать красиво», а прийти на интервью с тремя вещами: (1) руками потрогал то, о чём спросят, (2) умеешь объяснить вслух за 60 секунд, (3) есть честная история про пробелы (RoadRunner, крипта).

Правила, как на настоящем лайвкодинге: таймер, только документация, **без AI и без `solutions/`**. Подсмотрел - значит эту задачу ещё раз сделай через час с нуля.
После каждого блока - **проговорить вслух** вывод (диктофон на телефоне или в пустую комнату). Ответ «что я сделал и почему» - это и есть ответ на интервью.

Подъём: `make up` (php 8.4 + Postgres 16, порт 8010), `make test` (сейчас всё красное - так и задумано), `make seed` запустить в фоне в отдельной вкладке (~2 мин).

1. Задача 1 + `make race-naive` / `make race` (1,5 ч). 2. SQL №1, №6, №10 + блокировки A/B (1 ч). 3. Три крипто-ответа вслух (30 мин).

## Что можно пропустить, если HR-этап - только разговор
Задачи 2 и 3 и Octane не нужны для самого HR-этапа, но дают реальные «я пробовал» для технического собеседования, которое почти наверняка следом.

## Шпаргалка команд
```
make up | down | test | t F=<имя теста> | psql | seed | race | race-naive | octane | sh
```
Порты: приложение http://localhost:8010, Octane http://localhost:8011, Postgres localhost:54320 (user/pass/db: wallet/wallet/wallet; тестовая БД wallet_test).
